NestJS Realtime Patterns

Three independent demos. The server simulates incoming data for each one separately.

WebSocket disconnected

Socket.IO · namespace /chat · full-duplex

Server-Sent Events disconnected

GET /sse/stream · one request, many events · server → client

Long Polling stopped
